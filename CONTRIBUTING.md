# Contributing

1. Read `README.md`, `AGENTS.md`, and the architecture docs.
2. Create a short-lived branch from `main`.
3. Implement the smallest coherent change and include tests.
4. Run `pnpm run check` and `pnpm run format:check`.
5. Open a Pull Request using the template; describe evidence and risks.
6. Wait for review and required CI checks. Never commit secrets.

P0 is the initial `main` bootstrap; all subsequent development should go through PRs. No automatic merge or deployment is configured.
